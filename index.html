🤔 What is nth-prime-calculator?

nth-prime-calculator is an educational command-line program that helps you find the n-th prime number — the 1st prime, the 100th prime, the 1,000,000th prime, or any position you choose.

Think of prime numbers as the building blocks of mathematics. They're numbers that can only be divided evenly by 1 and themselves (like 2, 3, 5, 7, 11, and so on). This tool lets you jump straight to any position in that sequence without manually counting.

Who is it for? Perfect for students exploring number theory, programming beginners learning Python, math enthusiasts curious about prime patterns, or anyone who wants a quick, reliable way to explore primes on their computer or phone (via Termux).

✨ Key Features

  • 🔢 Calculate any n-th prime — from the 1st to the 100,000th and beyond
  • 🎓 Educational by design — includes clear comments in code to learn trial division

▶️ How to Run the Program

This is a Python program, so you'll need Python installed on your computer. If you don't have it yet, go to python.org and download the latest version for Windows.

After you've downloaded and unzipped the project folder, open your Command Prompt (search "cmd" in the Start menu) and follow these simple steps:

# Step 1: Go to the folder where you saved the project

cd path\to\nth-prime-calculator

# Step 2: Run the program

python nth_prime.py

Then just type in which prime number you want (like 5 for the 5th prime, or 1000 for the 1000th), press Enter, and watch the magic happen!
